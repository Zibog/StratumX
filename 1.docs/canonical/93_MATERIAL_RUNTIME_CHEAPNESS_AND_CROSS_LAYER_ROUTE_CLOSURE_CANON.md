# Material Runtime Cheapness And Cross Layer Route Closure Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Freeze one mandatory cheap-runtime contract and one class-wide implementation-tail contract for all material-owned routes.

This document exists so sleep/wake, consequence tiering, degraded substitutes, world persistence posture, viewport publication, and evidence are no longer scattered across per-button prose.

## Cheap-runtime master law
For every material-owned branch the archive must say, in one language:
- what is authoritative truth;
- what is a derived representation;
- what is a degraded substitute;
- when local solve is allowed or required;
- which branches must react immediately;
- which branches may use cached or postponed posture;
- how the chosen cheap rung is published to editor diagnostics;
- how validator proves the rung is legal.

## Mandatory cheapness fields
Every material-owned runtime posture must publish:
- `truth_owner_ref`
- `derived_representation_refs`
- `allowed_degraded_substitute_refs`
- `wake_trigger_classes`
- `immediate_branch_set`
- `cached_or_postponed_branch_set`
- `local_solve_gate_family`
- `cheap_rung_publish_signal`
- `validator_rule_family`
- `persistence_posture`
- `damage_field_posture`
- `fragment_absorption_posture`
- `far_summary_posture`

## Mandatory rung families
The active contour must at least normalize:
- `matresp.runtime.cheap.hot_exact`
- `matresp.runtime.cheap.local_reduced`
- `matresp.runtime.cheap.cached_local`
- `matresp.runtime.cheap.statistical_far`
- `matresp.runtime.cheap.retained_aftermath_only`

Each rung must say which of physics, damage topology, visual reveal, audio, light, and persistence remain exact, reduced, cached, postponed, or retained-only.

## Bounded-locality law
Cheapness is not fake-success law.
It is bounded-locality law.
The runtime may reduce representation richness, patch density, or fragment lifetime, but it may not silently change:
- material identity;
- response-profile choice;
- support-loss truth;
- perforation / ricochet / stop verdict;
- retained aftermath summary.

## Damage-field posture law
A damage field is legal only when all of the following are true:
- it is allocated on wake, not for every dormant instance;
- it has a bounded resolution family;
- it publishes when it is summarized back into compact state;
- it names the coarse support / occupancy state that other systems consume.

A material route is invalid if it requires permanent high-resolution damage fields for the whole world.

## Fragment posture law
Detached fragments are legal only when all of the following are true:
- fragment life is bounded;
- bounce count and settle window are bounded;
- sleep leads to merge, absorption, or explicit cleanup law;
- host absorption publishes a retained summary rather than keeping dead rigid bodies forever.

## Material-owned route closure law
Every material-owned `bind`, `mutate`, `preview`, `validate`, `rebuild`, `save`, or `import` route must publish:
- initiating surface;
- route id;
- packet / schema family;
- truth owner;
- validation gate family;
- invalidation scope;
- derived update scope;
- viewport and shell publication;
- persistence mode;
- recovery anchor;
- evidence relation;
- denial family;
- retry and focus law.

| material identity and binding | `route.material.bind.*` | archetype / surface / response / texture / profile binding |
| consequence preview | `route.material.preview.*` | bullet / blast / burn / wetness / aftermath preview |

| persistence and proof | `route.material.proof.*` | compare, capture, retain, freeze blocker review |
| damage topology | `route.material.damage.*` | damage-field build, summarize, rebuild, reveal refresh |
| fragment lifecycle | `route.material.fragment.*` | detach, sleep, merge-to-host, residue publication |

## Legal far-world posture
A far-world material is still lawful when it no longer holds rich local detail, provided it retains:
- stable material identity;
- stable territory family;
- stable consequence summary;
- stable support / traversal summary when applicable;
- stable char / wet / residue summary when applicable.

## Forbidden shortcuts
- one hidden per-material micro-solver that bypasses the declared rung ladder;
- fragment lifetimes that become unbounded because the camera is absent;
- keeping a dead rigid-body graveyard instead of merging into host state;
- using a visual-only breach with no retained support or occupancy digest;
- claiming old-floor success while silently deleting the cheap-rung publication.
