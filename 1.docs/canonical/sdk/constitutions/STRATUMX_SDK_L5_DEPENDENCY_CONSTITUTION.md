# STRATUMX_SDK_L5_DEPENDENCY_CONSTITUTION

## Scope
This constitution fixes legal dependency direction for the bridge.

## Binding laws
- `L5` depends downward on public `L4` surfaces and global umbrella law only;
- `L5` may align output shapes with upper-stack consumers without inheriting their ownership;
- `L5` may not depend on editor UI concepts, package orchestration, assistant workflow semantics, or planner state.

## Audit checks
- dependency docs name only legal lower or umbrella authorities;
- upper-stack concepts appear as consumers, never as owning dependencies;
- every local pack keeps dependency edges narrow and typed.
