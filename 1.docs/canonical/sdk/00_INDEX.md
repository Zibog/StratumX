# SDK Canonical Index

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
The sdk package owns public packets, observation classes, command acks, comparison surfaces, replay surfaces, compatibility law, and consumer-facing bridge contracts.

## Active sdk bands
- `47–57`: heavy-domain surface catalogs
- `58–63`: product, artifact, and launch surfaces
- `64–78`: truth-to-frame packets, diagnostics, compatibility, command/ack, and shell-capability catalogs
- `79–82`: authoritative heavy-domain constitutions
- `83–84`: photoreal fallback and first-playable progress catalogs
- `85–88`: heavy-domain companion catalogs for dto families, observation retention, transaction surfaces, and capture/replay consumers

## Role discipline
Constitutions define guarantees, failure classes, compatibility breaks, delivery law, and retention posture.
Catalogs enumerate fields, packets, consumers, and surface families.

## Gold note
SDK is `document_gold`.
