# Global Scope

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## What this archive covers

`canonical/` is the single authoritative documentation archive for the StratumX engine and editor stack.
It covers all four packages in their full authority:

- **engine**: runtime kernel, simulation, resource systems, startup — L-0 through L4
- **sdk**: data-oriented public bridge types, controls, observations, handles, refs — L5
- **tooling**: authority core, transaction ledger, snapshot/index/derived/artifact/stream/cache/budget planes, assistant runtimes, studio orchestration — L6, L6A, L7, L7A
- **editor**: authoring editor shell, viewports, panels, suites, services, collaboration — L8, L9, L10, L11

## What this archive does not cover

- Implementation source code (lives in workspace crates)
- Runtime executable binaries or build artifacts
- User documentation / manuals
- Project-specific content or data files
- Third-party library internals

## Global Gold Criterion

The archive reaches global **production gold** only when:

1. Every package has a complete active authority-root set and a complete active constitutional attachment set, proven by an active package-root-set completeness artifact rather than by package index presence alone.
2. Every `pass` row in every acceptance matrix cites a specific **Evidence ID** and an **active, existing** artifact.
3. No document is self-certifying (readiness must reference acceptance; acceptance must reference evidence artifacts).
4. No evidence registry row points to a non-existent file, and evidence existence is proven by an independent audit artifact rather than by the registry self-certifying itself.
5. No duplicate ordinals exist in any package root.
6. No wildcard/glob paths appear in root-level authority documents.
7. All hot/core layers across engine, sdk, tooling, and editor have full local documentation packages (not a single `00_LEVEL.md` only), and the active umbrella proof exposes an explicit hot/core level manifest.
8. All inter-package boundaries are formally stated, expressed as closed legal crossing sets, and non-contradictory with package root laws through an explicit contradiction matrix.
9. Version discipline is unified across all packages.
10. The global umbrella documents (this file and siblings) are complete, consistent, and prove one continuous legal relay path `engine -> sdk -> tooling -> editor` through a closed artifact-by-artifact relay manifest.
11. All four package audit readiness matrices are current against the active umbrella contour rather than only against historical local evidence packs.
12. Active test-result artifacts exist for all packages with executed document-package validation evidence (not just test-class coverage).
13. `31_GOLD_STATUS_STRATIFICATION_CANON.md` permits the stronger `production_gold` claim and no open reality/workflow blocker contradicts it.
