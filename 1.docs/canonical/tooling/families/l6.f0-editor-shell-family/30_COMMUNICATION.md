# Communication

This contract belongs specifically to the l6.f0 editor shell family and describes family-only coordination.


## Family-local communication for `editor_shell_family`
- coordination and refresh propagation related to shell composition, command bar, view hosting, docking, and editor frame routing
- coordination and refresh propagation related to authority-facing minimal truth: minimal shell authority refs only
- coordination and refresh propagation related to snapshot classes: shell snapshots and panel/view composition snapshots
- coordination and refresh propagation related to index classes: panel/view lookup indices
- coordination and refresh propagation related to derived classes: derived shell layouts and command routing views

## Note
The family coordinates these member concerns without introducing a new authority path.
