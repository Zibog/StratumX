# Data Responsibility

This contract belongs specifically to the l6.f0 editor shell family and describes family-only coordination.


## Family-scoped coordination for `editor_shell_family`
- locality, activation, and diagnostics around shell composition, command bar, view hosting, docking, and editor frame routing
- locality, activation, and diagnostics around authority-facing minimal truth: minimal shell authority refs only
- locality, activation, and diagnostics around snapshot classes: shell snapshots and panel/view composition snapshots
- locality, activation, and diagnostics around index classes: panel/view lookup indices
- locality, activation, and diagnostics around derived classes: derived shell layouts and command routing views

## Responsibility note
These coordination classes describe family behavior and do not replace member truth ownership.
