# Family Local Dependencies

This local family contract belongs specifically to the l7.f4 release meta family and may not be reused by a different family key.


## Allowed for `release_meta_family`
- member-local coordination for release campaign composition, release governance, and release reporting
- member-local coordination for authority-facing minimal truth: release campaign refs only
- member-local coordination for snapshot classes: release-campaign snapshots
- member-local coordination for index classes: release-campaign indices
- member-local coordination for derived classes: derived release campaign views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
