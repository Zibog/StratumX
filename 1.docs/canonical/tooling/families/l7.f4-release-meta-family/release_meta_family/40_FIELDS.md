# Family Local Fields

This local family contract belongs specifically to the l7.f4 release meta family and may not be reused by a different family key.


## Coordination records for `release_meta_family`
- coordination record for release campaign composition, release governance, and release reporting
- coordination record for authority-facing minimal truth: release campaign refs only
- coordination record for snapshot classes: release-campaign snapshots
- coordination record for index classes: release-campaign indices
- coordination record for derived classes: derived release campaign views

## Field note
Each local coordination record exists only to describe family locality and activation for these members.
