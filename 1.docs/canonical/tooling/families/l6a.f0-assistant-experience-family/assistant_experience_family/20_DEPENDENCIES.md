# Family Local Dependencies

This local family contract belongs specifically to the l6a.f0 assistant experience family and may not be reused by a different family key.


## Allowed for `assistant_experience_family`
- member-local coordination for assistant sessions, evidence pack composition, proposal experience, and assistant UI composition
- member-local coordination for authority-facing minimal truth: assistant session refs only
- member-local coordination for snapshot classes: assistant proposal and evidence snapshots
- member-local coordination for index classes: assistant lookup indices and proposal indices
- member-local coordination for derived classes: derived assistant proposal views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
