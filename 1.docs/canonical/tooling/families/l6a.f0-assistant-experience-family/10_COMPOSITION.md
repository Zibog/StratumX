# Composition

## Member composition
- assistant sessions, evidence pack composition, proposal experience, and assistant UI composition
- authority-facing minimal truth: assistant session refs only
- snapshot classes: assistant proposal and evidence snapshots
- index classes: assistant lookup indices and proposal indices
- derived classes: derived assistant proposal views

## Composition rule
The family exists to make domain adjacency for `assistant_experience_family` explicit, not to merge members into one truth owner.
