# Data Responsibility

This contract belongs specifically to the l6.f12 pack release authoring family family and describes family-only coordination.


## Family-scoped coordination for `pack_release_authoring_family`
- locality, activation, and diagnostics around build targets, bake graphs, cook graphs, release manifests, package closure, and release diagnostics
- locality, activation, and diagnostics around authority-facing minimal truth: target refs and explicit task intents only
- locality, activation, and diagnostics around snapshot classes: build/release status snapshots
- locality, activation, and diagnostics around index classes: target and manifest lookup indices
- locality, activation, and diagnostics around derived classes: readiness summaries and closure dashboards

## Responsibility note
These coordination classes describe family behavior and do not replace member truth ownership.
