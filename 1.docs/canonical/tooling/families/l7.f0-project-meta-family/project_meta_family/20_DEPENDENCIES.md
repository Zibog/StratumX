# Family Local Dependencies

This local family contract belongs specifically to the l7.f0 project meta family and may not be reused by a different family key.


## Allowed for `project_meta_family`
- member-local coordination for project orchestration, governance, and reporting composition
- member-local coordination for authority-facing minimal truth: project meta refs only
- member-local coordination for snapshot classes: project-orchestration snapshots
- member-local coordination for index classes: project-orchestration lookup indices
- member-local coordination for derived classes: derived project-meta views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
