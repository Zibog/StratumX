# Family Local Dependencies

This local family contract belongs specifically to the l6.f14 assistant family and may not be reused by a different family key.


## Allowed for `assistant_family`
- member-local coordination for assistant experience, proposal views, assistant diagnostics, and assistant task surfaces
- member-local coordination for authority-facing minimal truth: assistant interaction refs only
- member-local coordination for snapshot classes: assistant snapshots
- member-local coordination for index classes: assistant lookup indices
- member-local coordination for derived classes: derived assistant views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
