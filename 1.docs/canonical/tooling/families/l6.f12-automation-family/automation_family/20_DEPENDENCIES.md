# Family Local Dependencies

This local family contract belongs specifically to the l6.f12 automation family and may not be reused by a different family key.


## Allowed for `automation_family`
- member-local coordination for automation editor views, automation specs, and automation diagnostics
- member-local coordination for authority-facing minimal truth: automation edit intents
- member-local coordination for snapshot classes: automation snapshots
- member-local coordination for index classes: automation lookup indices
- member-local coordination for derived classes: derived automation views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
