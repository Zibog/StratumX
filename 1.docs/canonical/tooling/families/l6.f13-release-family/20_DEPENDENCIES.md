# Dependencies

This contract belongs specifically to the l6.f13 release family and describes family-only coordination.


## Family dependency posture for `release_family`
- family composition may touch release views, release packaging oversight, and release evidence presentation
- family composition may touch authority-facing minimal truth: release request intents only
- family composition may touch snapshot classes: release snapshots
- family composition may touch index classes: release lookup indices
- family composition may touch derived classes: derived release views
- package-root registries and lower packages only through member-legal public surfaces

## Forbidden widening
- new lower-stack truth not already legal for these members
- editor product UI ownership outside the family role
- hidden caches or mutable mirrors standing in for family coordination
