# Data Responsibility

This contract belongs specifically to the l6.f13 release family and describes family-only coordination.


## Family-scoped coordination for `release_family`
- locality, activation, and diagnostics around release views, release packaging oversight, and release evidence presentation
- locality, activation, and diagnostics around authority-facing minimal truth: release request intents only
- locality, activation, and diagnostics around snapshot classes: release snapshots
- locality, activation, and diagnostics around index classes: release lookup indices
- locality, activation, and diagnostics around derived classes: derived release views

## Responsibility note
These coordination classes describe family behavior and do not replace member truth ownership.
