# Family Local Dependencies

This local family contract belongs specifically to the l6.f13 release family and may not be reused by a different family key.


## Allowed for `release_family`
- member-local coordination for release views, release packaging oversight, and release evidence presentation
- member-local coordination for authority-facing minimal truth: release request intents only
- member-local coordination for snapshot classes: release snapshots
- member-local coordination for index classes: release lookup indices
- member-local coordination for derived classes: derived release views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
