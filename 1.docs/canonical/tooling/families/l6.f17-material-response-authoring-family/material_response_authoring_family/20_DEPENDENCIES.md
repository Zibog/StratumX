# Family Local Dependencies

This local family contract belongs specifically to the l6.f2 material response authoring family and may not be reused by a different family key.


## Allowed for `material_response_authoring_family`
- member-local coordination for material response authoring, reaction tables, and response rule authoring
- member-local coordination for authority-facing minimal truth: material-response edit intents
- member-local coordination for snapshot classes: response snapshots
- member-local coordination for index classes: response lookup indices
- member-local coordination for derived classes: derived response views
- package-root family registry and shared ids
- lower packages only through member-legal surfaces

## Forbidden
- undeclared member truth
- unrelated domain truth
