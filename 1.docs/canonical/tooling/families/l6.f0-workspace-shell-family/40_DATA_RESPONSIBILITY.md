# Data Responsibility

This contract belongs specifically to the l6.f0 workspace shell family family and describes family-only coordination.


## Family-scoped coordination for `workspace_shell_family`
- locality, activation, and diagnostics around workspace shell composition, layout sessions, focus/selection presentation, and workspace host routing
- locality, activation, and diagnostics around authority-facing minimal truth: workspace session ownership only
- locality, activation, and diagnostics around snapshot classes: workspace snapshots and session-scoped view snapshots
- locality, activation, and diagnostics around index classes: workspace/session lookup indices
- locality, activation, and diagnostics around derived classes: derived workspace panels and inspector views

## Responsibility note
These coordination classes describe family behavior and do not replace member truth ownership.
