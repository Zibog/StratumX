# Family Local Fields

This local family contract belongs specifically to the l6.f11 ui family and may not be reused by a different family key.


## Coordination records for `ui_family`
- coordination record for UI authoring, widget surfaces, UI schemas, and UI manifests
- coordination record for authority-facing minimal truth: UI edit intents
- coordination record for snapshot classes: UI snapshots
- coordination record for index classes: UI lookup indices
- coordination record for derived classes: derived UI views

## Field note
Each local coordination record exists only to describe family locality and activation for these members.
