# Communication

This contract belongs specifically to the l6.f11 ui family and describes family-only coordination.


## Family-local communication for `ui_family`
- coordination and refresh propagation related to UI authoring, widget surfaces, UI schemas, and UI manifests
- coordination and refresh propagation related to authority-facing minimal truth: UI edit intents
- coordination and refresh propagation related to snapshot classes: UI snapshots
- coordination and refresh propagation related to index classes: UI lookup indices
- coordination and refresh propagation related to derived classes: derived UI views

## Note
The family coordinates these member concerns without introducing a new authority path.
