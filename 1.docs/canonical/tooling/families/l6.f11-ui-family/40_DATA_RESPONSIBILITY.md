# Data Responsibility

This contract belongs specifically to the l6.f11 ui family and describes family-only coordination.


## Family-scoped coordination for `ui_family`
- locality, activation, and diagnostics around UI authoring, widget surfaces, UI schemas, and UI manifests
- locality, activation, and diagnostics around authority-facing minimal truth: UI edit intents
- locality, activation, and diagnostics around snapshot classes: UI snapshots
- locality, activation, and diagnostics around index classes: UI lookup indices
- locality, activation, and diagnostics around derived classes: derived UI views

## Responsibility note
These coordination classes describe family behavior and do not replace member truth ownership.
