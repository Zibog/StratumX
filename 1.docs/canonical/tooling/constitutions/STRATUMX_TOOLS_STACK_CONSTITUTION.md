# STRATUMX_TOOLS_STACK_CONSTITUTION

## Scope
This is the top-level constitution for the tooling stack spanning `L6`, `L6A`, `L7`, and `L7A`.

## Binding laws
- tooling composes authoring/runtime services above bridge truth without re-owning the engine;
- planes, sidecars, families, and campaigns each keep explicit authority boundaries;
- assistant and orchestration layers remain consumers/composers, not hidden stores.

## Audit checks
- every package map and level contract is compatible with the declared stack slope;
- no level silently becomes a second engine or a second editor shell;
- evidence/readiness stay aligned with the active stack registry.
