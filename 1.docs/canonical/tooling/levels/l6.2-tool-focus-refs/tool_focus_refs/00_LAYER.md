# tool_focus_refs

Role class: published tooling sidecar fact set

Canonical role:
own published focus refs for one active inspection or interaction target without owning widget focus behavior.

One data kind law:
this local pack owns only `tool_focus_refs` publications and the fields declared for them.

Minimal operational meaning:
publish published focus refs for one active inspection or interaction target without owning widget focus behavior so downstream tooling can route work without stealing editor ownership.

Forbidden drift:
actual OS/window focus, text-input caret ownership, multi-target selection truth, layout activation.
