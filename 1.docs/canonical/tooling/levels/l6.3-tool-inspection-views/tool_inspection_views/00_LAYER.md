# tool_inspection_views

Role class: published tooling sidecar fact set

Canonical role:
own structured inspection views generated from snapshots for inspectors, diagnostics, and property review surfaces.

One data kind law:
this local pack owns only `tool_inspection_views` publications and the fields declared for them.

Minimal operational meaning:
publish structured inspection views generated from snapshots for inspectors, diagnostics, and property review surfaces so downstream tooling can route work without stealing editor ownership.

Forbidden drift:
live widget trees, authoritative object mutation truth, preview rendering results, diagnostics event truth.
