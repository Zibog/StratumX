# tool_assistant_intents

Role class: published tooling sidecar fact set

Canonical role:
own assistant-originated suggestions or non-authoritative intents before they are lowered into legal commands.

One data kind law:
this local pack owns only `tool_assistant_intents` publications and the fields declared for them.

Minimal operational meaning:
publish assistant-originated suggestions or non-authoritative intents before they are lowered into legal commands so downstream tooling can route work without stealing editor ownership.

Forbidden drift:
final mutation commands, hidden model context not published through assistant runtime, UI chat transcript ownership, source asset/world truth.
