# tool_diagnostics_views

Role class: published tooling sidecar fact set

Canonical role:
own filtered and grouped diagnostics views for consumers that need stable issue presentations.

One data kind law:
this local pack owns only `tool_diagnostics_views` publications and the fields declared for them.

Minimal operational meaning:
publish filtered and grouped diagnostics views for consumers that need stable issue presentations so downstream tooling can route work without stealing editor ownership.

Forbidden drift:
event truth, acknowledgement state, source-runtime ownership, layout/widget rendering.
