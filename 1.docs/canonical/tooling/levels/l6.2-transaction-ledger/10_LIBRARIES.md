# Libraries

This contract belongs specifically to the transaction ledger level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `TransactionId` schema for `transaction_id`
- `CommandEnvelopeId` schema for `command_envelope_id`
- `AuthorityEpoch` schema for `before_authority_epoch`
- `AuthorityEpoch` schema for `after_authority_epoch`
- `TransactionOutcome` schema for `transaction_outcome`

## Declared registry use
- resolves or references `l6.0-authority-core`
- resolves or references `l6.1-command-envelopes`
