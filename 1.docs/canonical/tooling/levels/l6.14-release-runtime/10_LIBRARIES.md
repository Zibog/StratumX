# Libraries

This contract belongs specifically to the release runtime level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `ReleaseRunId` schema for `release_run_id`
- `ReleaseManifestId` schema for `release_manifest_id`
- `ArtifactSetRef` schema for `input_artifact_set`
- `PublicationChannel` schema for `publication_channel`
- `ReleaseOutcome` schema for `release_outcome`

## Declared registry use
- resolves or references `l6.6-artifact-plane`
- resolves or references `l6.7-stream-plane`
- resolves or references `l6.9-budget-runtime`
- resolves or references `l6.13-build-runtime`
