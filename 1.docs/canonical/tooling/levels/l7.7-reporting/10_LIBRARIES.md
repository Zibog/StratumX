# Libraries

This contract belongs specifically to the reporting level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `RecordId` schema for `reporting_record_id`
- `ScopeId` schema for `scope_id`
- `LifecycleState` schema for `state`
- `InputRefSet` schema for `input_ref_set`
- `OutputRefSet` schema for `output_ref_set`

## Declared registry use
- resolves or references `l6.3-snapshot-plane`
- resolves or references `l6.4-index-plane`
- resolves or references `l6.5-derived-plane`
- resolves or references `l6.6-artifact-plane`
