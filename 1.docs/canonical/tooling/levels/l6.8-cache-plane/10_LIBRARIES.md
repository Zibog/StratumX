# Libraries

This contract belongs specifically to the cache plane level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `CacheEntryId` schema for `cache_entry_id`
- `CacheClass` schema for `cache_class`
- `SourceDigest` schema for `source_digest`
- `EvictionPriority` schema for `eviction_priority`
- `CacheState` schema for `cache_state`

## Declared registry use
- resolves or references `l6.3-snapshot-plane`
- resolves or references `l6.4-index-plane`
- resolves or references `l6.5-derived-plane`
- resolves or references `l6.9-budget-runtime`
