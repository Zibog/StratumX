# Boundary Preservation

## Never owned here
- actual release artifacts
- signing secrets
- distribution credentials
- package manager installation truth

## Boundary law
`tool_release_intents` is a public sidecar mirror, not a stealth owner. It may expose routing, scope, or result references, but it may not absorb upstream editor ownership or downstream runtime/build truth.

## Drift alarm
If `tool_release_intents` starts storing widget state, runtime payloads, or authority truth, the sidecar has crossed its legal boundary and must be split or corrected.
