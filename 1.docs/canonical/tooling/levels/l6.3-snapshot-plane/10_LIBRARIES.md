# Libraries

This contract belongs specifically to the snapshot plane level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `SnapshotId` schema for `snapshot_id`
- `AuthorityEpoch` schema for `source_epoch`
- `SnapshotScope` schema for `snapshot_scope`
- `TransactionId` schema for `source_transaction_id`
- `SnapshotContentHash` schema for `content_hash`

## Declared registry use
- resolves or references `l6.0-authority-core`
- resolves or references `l6.2-transaction-ledger`
