# Libraries

This contract belongs specifically to the command envelopes level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `CommandEnvelopeId` schema for `command_envelope_id`
- `CommandKind` schema for `command_kind`
- `TargetRefSet` schema for `target_ref_set`
- `ToolSessionId` schema for `issuer_session_id`
- `MutationIntentDigest` schema for `mutation_intent_digest`

## Declared registry use
- resolves or references `l6.0-authority-core`
- resolves or references `l6.0-tool-session`
- resolves or references `l6.14-tool-task-requests`
