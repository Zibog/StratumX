# Libraries

This contract belongs specifically to the index plane level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `IndexId` schema for `index_id`
- `SnapshotSetRef` schema for `source_snapshot_set`
- `IndexedKeyspace` schema for `indexed_keyspace`
- `IndexFreshnessEpoch` schema for `freshness_epoch`
- `IndexRebuildReason` schema for `rebuild_reason`

## Declared registry use
- resolves or references `l6.3-snapshot-plane`
- resolves or references `l6.6-artifact-plane`
- resolves or references `l6.8-cache-plane`
