# Boundary Preservation

## Never owned here
- grouped issue views
- UI filter state
- mute/acknowledge policy state
- authority mutation truth

## Boundary law
`tool_diagnostics_events` is a public sidecar mirror, not a stealth owner. It may expose routing, scope, or result references, but it may not absorb upstream editor ownership or downstream runtime/build truth.

## Drift alarm
If `tool_diagnostics_events` starts storing widget state, runtime payloads, or authority truth, the sidecar has crossed its legal boundary and must be split or corrected.
