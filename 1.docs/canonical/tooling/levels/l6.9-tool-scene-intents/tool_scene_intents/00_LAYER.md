# tool_scene_intents

Role class: published tooling sidecar fact set

Canonical role:
own scene and world authoring intents before they are materialized as legal commands.

One data kind law:
this local pack owns only `tool_scene_intents` publications and the fields declared for them.

Minimal operational meaning:
publish scene and world authoring intents before they are materialized as legal commands so downstream tooling can route work without stealing editor ownership.

Forbidden drift:
scene mutation truth, cell streaming state ownership, runtime simulation state, UI hover/selection state.
