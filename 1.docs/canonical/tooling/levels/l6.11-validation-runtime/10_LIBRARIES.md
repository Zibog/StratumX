# Libraries

This contract belongs specifically to the validation runtime level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `ValidationRunId` schema for `validation_run_id`
- `ValidationScope` schema for `validation_scope`
- `ValidationRuleSetId` schema for `rule_set_id`
- `ValidationIssueSetRef` schema for `issue_set_ref`
- `ValidationOutcomeState` schema for `outcome_state`
