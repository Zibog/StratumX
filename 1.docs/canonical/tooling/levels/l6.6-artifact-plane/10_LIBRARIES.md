# Libraries

This contract belongs specifically to the artifact plane level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `ArtifactId` schema for `artifact_id`
- `ArtifactKind` schema for `artifact_kind`
- `SourceDigest` schema for `source_digest`
- `ContentDigest` schema for `content_digest`
- `ArtifactRetentionClass` schema for `retention_class`

## Declared registry use
- resolves or references `l6.3-snapshot-plane`
- resolves or references `l6.13-build-runtime`
- resolves or references `l6.14-release-runtime`
