# Libraries

This contract belongs specifically to the preview runtime level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `PreviewRunId` schema for `preview_run_id`
- `PreviewRequestId` schema for `preview_request_id`
- `PreviewKind` schema for `preview_kind`
- `SnapshotSetRef` schema for `source_snapshot_set`
- `PreviewResultRef` schema for `result_ref`
