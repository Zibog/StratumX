# Libraries

This contract belongs specifically to the build runtime level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `BuildJobId` schema for `build_job_id`
- `BuildTargetSet` schema for `build_target_set`
- `SourceDigest` schema for `input_digest`
- `WorkerClaimId` schema for `worker_claim_id`
- `BuildOutcome` schema for `build_outcome`

## Declared registry use
- resolves or references `l6.6-artifact-plane`
- resolves or references `l6.7-stream-plane`
- resolves or references `l6.9-budget-runtime`
- resolves or references `l6.11-validation-runtime`
