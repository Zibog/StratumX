# tool_activation_rules

Role class: published tooling sidecar fact set

Canonical role:
own tool activation rules, deny conditions, and prerequisite surfaces.

One data kind law:
this local pack owns only `tool_activation_rules` publications and the fields declared for them.

Minimal operational meaning:
publish tool activation rules, deny conditions, and prerequisite surfaces so downstream tooling can route work without stealing editor ownership.

Forbidden drift:
current activation truth, widget focus/layout ownership, tool execution results, policy state outside declared rules.
