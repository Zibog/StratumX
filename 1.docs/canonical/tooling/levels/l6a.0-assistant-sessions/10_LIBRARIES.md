# Libraries

This contract belongs specifically to the assistant sessions level and may not be reused verbatim by another tooling level.


## Local schemas and ids
- `RecordId` schema for `assistant_session_id`
- `AssistantSessionId` schema for `source_session_id`
- `LifecycleState` schema for `state`
- `SourceDigest` schema for `source_digest`
- `ResultRef` schema for `result_ref`

## Declared registry use
- resolves or references `l6a.0-assistant-sessions`
- resolves or references `l6.9-budget-runtime`
- resolves or references `l6.7-stream-plane`
