# Operator Blocker Recovery And Focus Return Routing Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Make blocker routing and focus recovery exact for heavy-domain authoring and proof lanes.

## Recovery families
| Blocker family | Recovery target |
|---|---|
| `IMP_*`, `AST_*`, `NRM_*` | import/canonicalization surfaces |
| `TRN_*`, `DST_*`, `HYD_*`, `FLD_*` | substrate lab |
| `WND_*`, `BIO_*`, `TAC_*`, `NAV_*`, `LIV_*` | living lab |
| `RND_*`, `LIT_*`, `AUD_*`, `PHR_*`, `TUN_*`, `CLM_*` | photoreal or climate proof labs |
| `PFR_*`, `SEAL_*` | first-playable workflow or release workbench |

## Focus law
Recovery must return the operator to the narrowest surface that can fix the blocker.
No blocker may eject the user to a generic dashboard without a focused next step.

## Publication law
Every recovery route emits:
- exact blocker code;
- surface id;
- first legal next action;
- stale artifact list if relevant.
