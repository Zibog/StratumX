# Heavy Domain Failure Blocker And Recovery Routing Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Define blocker families, recovery targets, and focus-return law for heavy-domain routing.

## Mandatory blocker classes
| Blocker class | Meaning | Recovery target |
|---|---|---|
| import blocker | source or family invalid | source intake or family selector |
| schema blocker | missing or illegal packet fields | exact schema field row |
| transaction blocker | target scope/state illegal | originating editor control or target picker |
| cook blocker | artifact build failed | cook stage diagnostics |
| compare blocker | baseline missing or incompatible | corpus selector or compatibility row |
| certification blocker | required evidence missing or law broken | certification checklist row |
| seal blocker | index/ledger/coverage/readiness out of sync | release workbench exact failing row |

## Recovery law
Every blocker must publish:
- first blocker code;
- exact stage where it occurred;
- recommended next legal action;
- focus return target;
- stale artifacts that cannot be trusted until recovery.

## Forbidden shortcut
No blocker may be “resolved” by dropping required evidence or hiding a downgrade row.
