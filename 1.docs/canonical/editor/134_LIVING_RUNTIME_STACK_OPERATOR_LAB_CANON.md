# Living Runtime Stack Operator Lab Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Provide one production-hard living lab instead of scattered debug islands.

## Mandatory tabs
- body layers and wound chain
- needs and schedules
- social memory and status
- squad intent and reservation
- ecology and migration
- dialogue boundary and semantic memory
- explanation timeline

## Mandatory fields
`species_class`, `body_layer_state`, `need_pressure`, `schedule_state`, `social_status`, `squad_intent`, `migration_front_id`, `dialogue_window_state`, `explanation_anchor_id`

## Required actions
- inspect layered traversal;
- inspect schedule and need deltas;
- inspect squad reservations and cover validity;
- inspect migration triggers;
- inspect dialogue request and fallback lineage;
- request why-this-happened explanation.

## Disabled reasons
`LIV_DISABLED_NO_AGENT_SCOPE`, `LIV_DISABLED_SPECIES_CLASS_MISSING`, `LIV_DISABLED_EXPLANATION_ANCHOR_MISSING`
