# Editor Canonical Index

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
The editor package owns operator-visible workspaces, labs, playbooks, diagnostics, capture/review surfaces, release dashboards, and the human-grade shell that lets creators move through those systems without losing context.
It does not own runtime truth.

## Editor navigation spine

### Base workstation and creator shell
- `82`, `86–89`: bootstrap/build, simulate/fix/retest, certification, status, and orchestra dashboards
- `110–113`: exact buttons, menu tree, material-first sequence, and material-centric surface
- `114–118`: workspace/docking, honest viewport, assistant/extensions, sequential creator strip, and native file/project UX
- `128–131`: visual language, layered world conveyor, viewport cockpit, and constellation navigation

### Core production labs

- `132–138`: world-scale lane, physical substrate lane, living runtime lane, photoreal tunnel proof lane, climate theater lane, society/tactics suite, and wound/species consequence lab

### Domain companions
- `58–80`: physics, destruction, lookdev, camera, audio, large world, hydrology, weather, cloth/fur, living, tactics, wounds, dialogue, floor, animation, nav, persistence, inventory, quest, and causality debug
- `90–109`: frame/render/material/texture/light/audio/animation/VFX/UI/diagnostics/platform/budget/certification/evidence/playbooks dashboards

## Role discipline
Shell docs define shell behavior.
Labs define controls, overlays, inspectors, disabled reasons, and captures.
Playbooks define ordered routes.
The editor package may orchestrate truth but may not own it.

## Gold note
The editor package is `document_gold`.
This does not mean every linked runtime family is equally live.
