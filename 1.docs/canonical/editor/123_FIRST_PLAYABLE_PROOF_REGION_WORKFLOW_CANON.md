# First Playable Proof Region Workflow Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Freeze the exact operator route from empty project to one strong proof region.

## Workflow

| Step | Required artifact or verdict | Primary blocker family |
|---|---|---|
| create/open project | project identity and workspace | `PFR_PROJECT_*` |
| open world package | world-open verdict and ring legality | `PFR_WORLD_*` |
| bind terrain and material set | visible terrain/material corridor | `PFR_TERRAIN_*` |
| bind sky / time / weather | climate-ready world state | `PFR_CLIMATE_*` |
| place or load one tunnel/basement proof pocket | proof pocket identity | `PFR_POCKET_*` |
| validate world and ring posture | observability verdict and distance rung digest | `PFR_RING_*` |
| run one destruction + audio + lighting proof pass | proof-run result bundle | `PFR_SLICE_*` |
| capture first-playable bundle | retained artifact refs | `PFR_CAPTURE_*` |
| review readiness | readiness and seal-review packet | `PFR_REVIEW_*` |

## Success condition
The lane closes only when terrain, sky, tunnel proof pocket, destruction aftermath, audio continuity, and capture bundle all exist in one lawful chain.

## Focus recovery law
A blocker must return the operator to the narrowest fixing surface:
terrain lab, climate lab, tunnel proof lab, living lab, or release workbench.
