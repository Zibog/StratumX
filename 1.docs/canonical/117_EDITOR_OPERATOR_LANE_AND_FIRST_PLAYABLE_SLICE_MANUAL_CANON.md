**Stack version:** `SX-CANON/1.0.28/STACK-v34`

## Purpose
Freeze the human operator lanes that matter most for the dream-stack so the editor grows as a serious workstation rather than a pile of disconnected labs.

## Operator law
Every lane must expose:
- one narrow start point;
- one explicit set of controls;
- one set of overlays and inspectors;
- one blocker surface with focused recovery;
- one capture or compare handoff;
- one path back to the shell without losing context.

## First-playable slice
The canonical first playable slice is narrow on purpose:
- one project,
- one world package,
- one terrain/material corridor or chamber,
- one sky or confined-lighting posture,
- one destruction event,
- one audible material and lighting loop,
- one retained capture bundle,
- one release review surface.

## Operator completion checklist
A lane is not operator-complete until it names:
- entry command or menu route;
- primary inspector fields;
- primary overlays;
- disabled reasons;
- capture/replay handoff;
- compare or certification handoff.
