## Purpose

It answers five things at once:
which technology family exists, where runtime truth lives, which SDK contract carries it, which tooling conveyor or route legalizes it, which editor surface exposes it, and what the honest present-tense posture is.

## Description law
A technology family is considered described only when:
- one root anchor names the family and its companions;
- one engine truth owner or explicit non-engine exception exists;
- one SDK bridge names public packets or surfaces;
- one tooling route names stage, blockers, artifacts, and focus return;
- one editor surface names controls, overlays, inspectors, and disabled reasons where relevant;
- one honest posture row says whether runtime proof is still open.

## Gold law
`document_gold` means the active canonical archive is singular, navigable, role-disciplined, and technology-described.
It does **not** mean the full runtime implementation breadth is proven.
