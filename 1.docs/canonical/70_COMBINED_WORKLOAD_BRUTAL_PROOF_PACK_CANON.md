## Exact review bundle
Every combined pack review must show:
- baseline run;
- failed run if any;
- recovery run;
- active ladder trace;
- threshold rows that triggered each transition;
- compare digest;
- freeze blocker summary;
- last-good baseline id;
- operator signoff decision.

## Execution law
A combined pack is not wide-code-wave evidence by itself.
It is the docs-level execution contract that later code proof packs must implement without changing the pack vocabulary.
