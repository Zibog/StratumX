# First Product Result Canon

**Stack version:** `SX-CANON/1.0.28/STACK-v34`

## Purpose
This canon freezes the first undeniable product proof rail.
It is not the identity of the engine.
It is the narrow proving route that shows the stack can move from operator action to a real emitted product.

## First-product result
The first result is closed when one operator can:
1. create a project from a legal template;
2. save project state and build profile;
3. build a desktop product;
4. export a launchable executable artifact;
5. launch the last good build;
6. receive a runtime signature proving the product ran; and
7. verify the first-result text signature `ты победил`.

## Why this exists
Without this rail the archive can describe technology forever without proving that editor, tooling, sdk, and engine already form one product.
With this rail the stack has one narrow but honest proof path.

## Non-ownership law
This proving rail does not own the engine.
The engine remains technology-first.
The proving rail is only:
- a minimal product proof;
- a sanity check for the route from operator to executable artifact;
- a legal benchmark for future broader products.

## Required cross-package route
| Step | Primary package owner | Expected product |
|---|---|---|
| Create Project | editor -> tooling | workspace + project identity |
| Save Project | editor -> tooling -> sdk | saveable project state |
| Build Desktop Product | editor -> tooling -> sdk -> engine/runtime packaging | built artifact set |
| Export Desktop Product | editor -> tooling | launchable executable in target output |
| Launch Last Build | editor -> tooling -> engine/runtime | running process with diagnostics return |
| Verify Signature | engine/runtime -> sdk -> tooling -> editor | first-result signature `ты победил` |


## Failure law
The rail is invalid if:
- the executable is editor-only and not an emitted product artifact;
- the signature is hardcoded in editor without runtime confirmation;
- build and export are faked or skipped;
- the launch result cannot return diagnostics and signature observations.

## Current posture
The proving rail is allowed to be `partial_live`.
It may not be used to fake `production_gold`.
