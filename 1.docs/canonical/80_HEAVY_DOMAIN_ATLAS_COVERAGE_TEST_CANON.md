# Heavy Domain Atlas Coverage Test Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Define the mandatory atlas-coverage test that prevents phase drift between workload promises and executable routes.

## Assertions
For every workload phenomenon in root `76`, the archive must expose:
1. one engine truth owner;
2. one sdk packet-family set;
3. one tooling route family;
4. one promoted editor lab or dashboard;
5. one diagnostics surface in `editor/100` or an owning production lab;
6. one compare mode;
7. one capture mode;
8. one recovery action;
9. one certification pack.

## Required evidence
- root `72` atlas extract;
- root `76` signal map extract;
- `editor/110` promoted button extract;
- diagnostics-surface extract from `editor/100`;
- certification-pack extract from root `65`, `68–70`;
- one live conformance sample per promoted phenomenon family.

## Failure posture
Missing any required column or any unresolved link marks the atlas incomplete.

## Phase linkage
This test is mandatory for phase 1 exit because later phases may not add world proof on top of an incomplete route atlas.
