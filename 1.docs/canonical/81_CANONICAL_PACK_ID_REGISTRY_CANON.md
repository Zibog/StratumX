## Law
- aliases listed here are forbidden in active docs, artifacts, and evidence bundles;
- a pack id must map to one owning route family cluster only;
- pack id punctuation drift is forbidden;
- combined workload docs must cite canonical `pack.*` ids only;
- freeze review must cite canonical pack ids only.


## Phase-6 review law
The registry above is sufficient for the active documentation contour.
Phase 6 does not introduce a second pack namespace for regression, freeze, or scale.
Instead:
- regression reviews must aggregate only the canonical packs already declared above;
- freeze review must cite only the canonical packs already declared above;
- region-scale validation must cite only the canonical packs already declared above;
- dashboards may summarize many packs, but the retained bundle chain must always resolve back to these canonical rows.
