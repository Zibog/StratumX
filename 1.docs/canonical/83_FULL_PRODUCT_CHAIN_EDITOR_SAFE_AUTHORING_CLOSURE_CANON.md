# Full Product Chain Editor Safe Authoring Closure Canon

**Stack version:** `SX-CANON/1.0.24/STACK-v30`

## Purpose
Freeze the root-level closure statement for an editor-safe product chain.

This file is not a marketing summary.
It is the directive that says what the archive must already close before the editor is allowed to claim a lawful product-authoring contour.

## Mandatory closure bands
The active contour is accepted only if all of the following are simultaneously true:
- base shell is clean and non-demo;
- promoted day-zero actions resolve through exact button rows;
- world package, validation, and save/restore law are singular;
- material law owns downstream physical, visual, audio, light, runtime, persistence, and proof branches where declared owner;
- editor exposes one material-centric operator surface rather than scattering material authority across unrelated labs;
- material-owned routes publish one class-wide implementation-tail law;
- material-owned preview, compare, capture, and freeze routes are retained-evidence capable rather than shell-only hints.

## Product-safe conveyor bands
### Day-zero conveyor
`project -> world -> terrain -> material -> sky -> validate`

### Material-centric conveyor
`identity -> state/modulation -> physical branch -> visual branch -> audio branch -> light branch -> cheap runtime -> preview/coverage -> validation -> evidence`

### Full product ladder
`project -> world -> terrain/material/environment -> gameplay/population/systems -> preview/validate -> capture/compare/freeze -> build/export/launch`

## Forbidden posture
The archive is not product-safe if any of the following remain true:
- a promoted button exists outside `editor/110`;
- a material-owned branch is described only by loose prose and not by normalized family vocabulary;
- runtime cheapness, persistence, or proof closure exists only as neighboring hints instead of one mandatory contract;
- freeze review can succeed without retained material branch evidence where material law is the declared owner.
