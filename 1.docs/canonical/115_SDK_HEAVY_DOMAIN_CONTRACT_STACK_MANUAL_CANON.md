# SDK Heavy Domain Contract Stack Manual Canon

**Stack version:** `SX-CANON/1.0.28/STACK-v34`

## Purpose
Provide the stitched reading spine for heavy-domain public contracts so implementers can move from runtime truth to public packets, observations, transactions, replay, and compare without inventing extra bridge law.

## Scope of this manual
This manual stitches:
- root `105–107`, `115`;
- sdk `79–88`;
- engine heavy constitutions as packet producers;
- tooling `83–92` as packet consumers and routers;
- editor `119–138` as human consumers.

## Reading order
1. root `105–107` for dto, transaction, and replay law;
2. sdk `79–82` for authoritative constitutions;
3. sdk `83–88` for companion catalogs and consumer tables;
4. tooling `83–92` for routes, invalidation, compare, and recovery;
5. editor lanes and labs for operator use.

## Mandatory exact outcomes
- packet families, observation classes, transactions, and replay bundles are named once;
- delivery cadence, retention, compatibility, and failure law are explicit;
- consumer entitlement is explicit;
- first-playable proof packets are narrow but not ad-hoc;
- release review can audit the heavy contract stack without reading engine-private structs.
