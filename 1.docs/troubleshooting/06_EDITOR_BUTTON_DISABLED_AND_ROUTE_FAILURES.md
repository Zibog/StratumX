# Editor Button Disabled and Route Failures

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **troubleshooting**.


| Disabled reason | Recovery |
|---|---|
| Project not open | open/create project. |
| Selection required | select valid object. |
| Route blocked | open blocker details and required precondition. |
| Evidence missing | run capture or compare. |
| Backend unavailable | run Render Doctor. |
| Import invalid | open import validation panel. |
