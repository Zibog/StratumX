# Asset Import, Model, Collision, and LOD Failures

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **troubleshooting**.


| Failure | Recovery |
|---|---|
| Unsupported format | convert or add parser adapter. |
| Wrong scale/axis | set import normalization profile. |
| Missing material slot | assign slot mapping. |
| Skeleton incompatible | choose compatible skeleton or remap. |
| Collision generation failed | choose simplified hull or provide source collision. |
| LOD/proxy missing | generate or mark asset non-large-world eligible. |
