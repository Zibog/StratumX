# Empty Project to Showable Frame

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **tutorial**.


1. Create empty project.
2. Select default world template.
3. Open graphics backend lab.
4. Choose Auto backend policy.
5. Run Render Doctor.
6. Add terrain tile.
7. Assign default PBR material.
8. Enable sky/sun baseline.
9. Enable exposure/tonemap.
10. Capture frame.
11. Confirm artifact contains backend, framegraph, material, shader, and camera metadata.
