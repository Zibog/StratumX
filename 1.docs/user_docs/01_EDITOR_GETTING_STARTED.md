# Editor Getting Started

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **user manual**.


## First session

1. Open or create project.
2. Open world workspace.
3. Confirm backend badge.
4. Open content browser.
5. Open viewport diagnostics.
6. Use capture button to create first evidence artifact.

If a button is disabled, open the disabled reason rail before changing content.
