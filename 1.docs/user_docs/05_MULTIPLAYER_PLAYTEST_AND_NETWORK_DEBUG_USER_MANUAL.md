# Multiplayer Playtest and Network Debug User Manual

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **user manual**.


## Start playtest

1. Open Multiplayer Lab.
2. Choose local server/client count.
3. Select latency/loss profile.
4. Start session.
5. Open replication inspector.
6. Move controlled actor and watch prediction correction.
7. If desync appears, capture trace and open replay.
