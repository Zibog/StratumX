# Capture, Compare, and Troubleshooting User Manual

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **user manual**.


## Capture flow

1. Click Capture.
2. Name scenario.
3. Confirm artifact path.
4. Compare against baseline if available.
5. Open mismatch details.
6. Use recovery route suggested by diagnostics.
7. Freeze only if evidence is retained.
