# Graphics Viewport and Showable Frame User Manual

Stack version: `SX-CANON/1.0.27/STACK-v33`

Role: **user manual**.


## First beautiful frame

1. Open project.
2. Select render backend policy: Auto.
3. Open Render Doctor and confirm selected backend.
4. Load terrain tile.
5. Assign material.
6. Enable sky/sun baseline.
7. Enable exposure/tonemap.
8. Capture frame.
9. Review metadata: backend, feature tier, shader variants, material ids, framegraph passes.
