# Weather Maps

Regional bias maps for artistic control of weather patterns across the world.

## Files

- `default_weather_map.png` - Default weather distribution (1024x1024)
- `cloud_coverage_map.png` - Where clouds form more frequently
- `regional_humidity_bias.png` - Humidity variation across regions
- `regional_storm_bias.png` - Storm probability by region

## Purpose

These maps allow artists to control:
- "This area has more fog"
- "This region gets more storms"
- "This zone is drier"
- "Storm fronts move faster here"

## Format

PNG, 1024x1024, grayscale or RGB depending on data
